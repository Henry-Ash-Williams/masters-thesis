\chapter{Discussion}

\noindent\fbox{%
    \parbox{\textwidth}{%
        \textbf{Word Count: 4000}

        \begin{itemize}
            \item Are dynamic methods vulnerable to advanced obfuscation techniques? 
            
            \begin{itemize}
                \item It's possible to hide API calls from standard API call hooking techniques 
                \item Other redundant API calls may be made to obfuscate call sequences 
                \item Advanced malware (i.e. Rootkits) are able to stealthily perform malicious actions on the host
            \end{itemize}

            \item Are opcode sequences suitable features for NLP based malware detection? 
            
            \begin{itemize}
                \item Full disassembly may offer provide better information for transformer architectures 
                \item Was not tested due to time/compute limitations 
                \item Byte-level modelling may work, but the presence of polymorphic malware and encrypted payloads may be challenging to model accurately  
            \end{itemize}

            \item Is executable packing (UPX) a good proxy for the obfuscation methods seen in the wild? 
            
            \begin{itemize}
                \item What other obfuscation techniques and solutions could work for this? 
            \end{itemize}

            \item Could diffusion modelling enable machine de-obfuscation? 

            \begin{itemize}
                \item Obfuscation is analgous to noise in a signal 
                \item Diffusion models are well suited to denoising of data 
                \item Might be able to de-obfuscate programs to generate large scale 
            \end{itemize}

            \item Data limitations
            
            \begin{itemize}
                \item Lack of large-scale, benign executable datasets 
                \item High presence of obfuscation in real-world malware samples 
                \item Unobfuscated malware samples are not representative of malware seen in the wild as they are often ``toy'' projects, and lack advanced capabilities 
                \item Unobfuscated, advanced malware are hard to find   
            \end{itemize}

            \item Conclusion 
        \end{itemize}
    }%
}
